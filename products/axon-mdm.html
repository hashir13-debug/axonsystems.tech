Axon MDM

Lock down shop phones from an owner's console.

KotlinDevice Owner APIsLAN discovery

A shop phone does the one job it was bought for: the owner decides from a console what it can open, and can see or lock it without walking to the counter.

The problem

A phone handed to someone at work is a phone that can be reconfigured, tethered, or filled with whatever anybody installs.

What it does

Two paired apps. The owner console sets policy and finds every shop phone on the same Wi-Fi, or generates an offline setup code for a phone with no link yet. The shop app runs on each shop phone, paired by a PIN shared across them.

Policies cover the Settings app, mobile hotspot, Bluetooth, Wi-Fi configuration, and per-package lists of apps to lock or hide.

Details

  • Paired owner console and shop app, linked by one shared PIN
  • Lock Settings, block hotspot and Bluetooth, lock Wi-Fi config, hide or lock any app
  • Offline setup code for a phone with no network link yet
